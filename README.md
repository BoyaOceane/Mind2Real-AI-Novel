# 即文 · Mind2Real — AI小说生成器与同人创作工具

**所想，即成文。**

下载体验包请访问 [GitHub Releases](https://github.com/BoyaOceane/Mind2Real-AI-Novel/releases)。选择适合系统的 ZIP，完整解压后按包内说明启动，再填写自己的 API Key。

写你想看的故事。

**即文（Mind2Real）是面向 PC 浏览器的 AI 小说生成器，帮助读者和创作者把剧情想法写成专属爽文，支持同人创作，也能随用户选择继续发展故事。**

有没有一本小说，题材、人设、关系和爽点都刚好合你的心意？

在「即文」，你把想法说出来，AI帮你把它写成能一路追下去的专属爽文。想在喜欢的游戏世界里冒险，想和熟悉的角色并肩，想经营自己的小店，或者只想痛痛快快地赢一次——故事从你的愿望开始。

> 你决定想看什么，AI补足场面与过程。每一次选择，都可以让故事走向更合你心意的方向。

项目原名「即墨（Jimo）」，当前优先支持 PC 浏览器。

## 你说想看什么，故事就从哪里开始

- **有想法，直接写。** 描述题材、主线、人设或想体验的关系，先看生成的书名与抓人简介，喜欢就进入。
- **没想法，也能开读。** 自动随机世界与身份背景，准备一份有优势、有期待的爽文开局。
- **像追更一样轻松。** 短段阅读、流式生成，点击“继续看”推进剧情；想换方向，可以选完整行动选项，也可以直接说出自己的想法。
- **爽得有理由。** 能力有边界，关系有铺垫，选择有后果，收获能在后续故事里用上。爽点可以是胜利、被偏爱、经营收益、破局或自由，不只是一遍遍打脸。
- **把自己放进故事。** 可设置姓名与性别；不填姓名时以“你”进入。题材、想看与不想看的内容放在独立阅读偏好中，可选测评不阻挡开读。

剧情想法与阅读偏好共同影响生成；两者冲突时，剧情想法优先，未冲突的偏好继续生效。清空想法后，新生成不再使用旧想法，恢复按阅读偏好随机准备。阅读过程中也能更新想法，影响后续内容，已有剧情不会被悄悄重写。

## 支持同人创作

输入喜欢的作品名，再说说你想看的剧情，就能开始创作自己的同人故事。

## 如何使用即文：从下载到读到第一段故事

需要 Python 3、PC 浏览器，以及可用的 DeepSeek API Key。项目使用纯 HTML / CSS / JavaScript，无需安装 Node.js、前端依赖或运行构建命令。

### 1. 下载并启动

在 [GitHub 仓库](https://github.com/BoyaOceane/Mind2Real-AI-Novel) 点击 **Code → Download ZIP**，解压后在包含 `index.html` 的目录打开终端。

已安装 Git 的用户也可以下载 `main` 分支：

```powershell
git clone --branch main https://github.com/BoyaOceane/Mind2Real-AI-Novel.git
cd Mind2Real-AI-Novel
```

在项目目录启动本地服务：

```powershell
python -m http.server 8080
```

Windows 若找不到 `python`，可尝试 `py -m http.server 8080`；macOS / Linux 通常使用 `python3 -m http.server 8080`。保持终端运行，浏览器打开 **http://localhost:8080**。请通过这个地址访问，不要直接双击 HTML 文件。

### 2. 设置模型

点击首页 **“API设置”**，填写并保存自己的 DeepSeek API Key。当前默认模型为 `deepseek-flash`，设置中另有 `deepseek-v4-pro`；仓库不提供 Key，实际调用费用由使用者承担。

### 3. 描述想看的剧情，先看简介

在首页 **“这次想看什么”** 中写下题材、主角想做什么、想体验的关系或爽点，然后点击 **“生成简介”**。

原创剧情可以这样描述：

> 我想看修仙爽文，开局天赋满级，一路升级逆袭。

同人剧情可以这样描述：

> 《游戏名》，穿越到游戏世界与各个角色展开冒险。

作品和剧情都可以换成自己喜欢的。不知道从哪里开始，也可以留空，让它随机准备一个世界与身份。

### 4. 进入故事，决定下一步

喜欢生成的书名与简介，就点击 **“进入这个世界”**。在阅读页点击 **“继续看”** 追读，或展开改走向，选择行动、输入你希望发生的剧情。开篇通常约250–450字，续写约350–600字，关键场面可适当延长。

姓名、性别和较稳定的题材偏好在首页 **“阅读偏好”** 中设置；测评可跳过，姓名留空用“你”。首页剧情想法优先于已存偏好，清空后恢复偏好随机；阅读中更新偏好需应用后才影响后续生成。

如需补充信息，按页面提示填写后重试即可。

### 5. 保存和备份

故事会在本机自动保存，首页 **“历史记录”** 可继续阅读。阅读页的 **“更多” → “创作工具”** 中可 **“导出正文”** 或 **“备份 JSON”**。清理浏览器数据前请先备份。

### 常见启动问题

- 页面打不开：确认服务终端仍在运行，并访问 `http://localhost:8080`。
- 8080端口被占用：改用 `python -m http.server 8081`，再访问 `http://localhost:8081`。地址改变会使用另一份浏览器存储，旧小说请从原地址备份后导入。
- 模型没有回应：检查 API Key、账户可用额度、网络与模型设置；保留草稿后重试。API调用是否成功与小说文笔是否合意需要分别判断。

## 关于这款AI小说工具

### 即文适合谁？

想读符合自己口味的个性化爽文、想用轻松方式延伸剧情想法、想在熟悉的原作世界中体验同人故事的人。用户决定主线与关键爽点，AI辅助扩展动作、对白与过程。

### 能创作原创小说和同人小说吗？

支持原创小说和同人创作。描述想看的剧情，或填写喜欢的作品名，就可以开始。

### 是免费在线小说网站吗？

当前提供本地运行的项目，本文不提供在线体验地址。模型使用自己的DeepSeek API Key，可能产生调用费用；项目没有账号、云同步或免费模型额度。

### English overview

**Mind2Real (即文) is a browser-based AI story generator for personalized fiction and fanfiction.** Users describe the story they want to read, preview a title and synopsis, and continue through short immersive episodes or their own choices. It supports fanfiction, runs locally, and uses a user-provided DeepSeek API key.

## 小说存在哪里？

剧情、书架、偏好与 API Key 保存在当前浏览器、当前网站地址的本地存储中，**不会自动上传到 GitHub**，也没有账号或云同步。

生成时，浏览器会直接向 DeepSeek 发送本次请求；续写请求包含已有剧情与相关设定，用作上下文。请使用页面中的“备份 JSON”保存故事；清除网站数据或更换浏览器、访问地址后，原记录可能不可见。支持正文导出、草稿恢复和旧档兼容。

## 项目文件

本仓库是即文的公开发布仓库，只维护 `main` 分支。

| 页面 | 用途 |
|---|---|
| `index.html` | 剧情想法、随机开局、书名简介与书架 |
| `story.html` | 沉浸阅读、继续看、改走向与创作工具 |
| `profile.html` | 题材与排除、姓名性别、独立可选测评 |
| `admin.html` | 世界、人物、剧情与文风提示配置 |

当前优先支持 PC 浏览器。自动检查使用模拟模型响应，实际文笔、爽感和原著准确度仍需试读。
